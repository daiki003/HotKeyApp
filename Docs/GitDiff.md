# Git 差分画面

左上の表示モードを切り替えて差分を確認できる。

| モード | 比較する内容 |
| --- | --- |
| 未コミットの差分 | 未ステージ・ステージ済み・スタッシュ準備群に分けて表示 |
| ベースとの差分（未コミット含む） | 設定済みベースブランチの先端から現在の作業ツリーまでの差分。コミット済み・未コミット・未追跡を含む |
| コミットの差分 | 選択したコミットと第1親の差分。初回コミットは空のツリーと比較 |

ベースブランチは「Git 設定 > リポジトリ名」の設定を使用する。比較はローカルで取得済みの情報に基づく。
コミット・ベース比較では、ステージ・破棄・スタッシュ準備などの作業ファイルを変更する操作は利用できない。

## 並べ替え

変更ファイルの右側で「パス順」「ファイル名順」「変更種類順」「手動順」を選択する。
同じグループのファイルをドラッグするか、ファイル選択中に `Shift+↑` / `Shift+↓` を押すと手動で並べ替えられる。
手動順はウィンドウを開いている間、一覧更新後も維持される。

## コミットを指定

スタッシュボタンの下にある「直近コミット」を展開し、コミットを選択する。現在の履歴から直近50件を表示する。
それより古いコミットや別の履歴は入力欄に SHA・タグ・`HEAD~10` などを指定し、「表示」または Enter で開ける。

## 退避してベースを取り込み

ボタンを押すと、次の順番で実行する。

1. 未追跡ファイルを含む現在の変更をスタッシュする。
2. ベースにリモート追跡先があれば fetch し、その先端を現在のブランチへ merge する。追跡先がなければローカルのベースを merge する。
3. 今回作成したスタッシュを、ステージ状態も含めて復元する。
4. 復元に成功した場合だけ、今回のスタッシュを削除する。既存のスタッシュは保持する。

マージの失敗時は復元を中止する。復元の失敗時もスタッシュを保持し、画面下部へスタッシュの SHA と復旧用コマンドを表示する。
競合・進行中の Git 操作がある場合や、変更のあるサブモジュールがある場合は実行を中止する。
現在のブランチをベースとして指定することはできない。

## 差分内検索

- `Ctrl+F`: 表示中のファイルを検索する。
- `Ctrl+Shift+F`: 選択中モードの全差分を検索する。「全差分」チェックでも切り替えられる。
- Enter または「検索」: 検索を実行する。
- 検索結果を選択: 対象ファイルを開き、一致箇所を選択してスクロールする。
- `F3` / `Shift+F3`: 次／前の一致箇所へ移動する。

検索は大文字・小文字を区別しない通常の文字列検索。追加・削除行と差分の前後の行を対象とし、ファイル全体の変更されていない部分やバイナリの内容は対象外。
通常表示の20,000行制限より後ろも検索できる。結果が5,000件に達した場合は表示を打ち切るため、検索語を絞り込む。
