# ボタン作成画面

## 既知のデグレ

- [ ] 起動直後に誤ったコントロールへフォーカスが入る
  - 発生条件: ステップが切り替わった直後やダイアログ初期表示時
  - 影響: キーボード入力が想定外の場所に入る
  - 確認方法: 画面表示直後に、現在のステップに応じた入力先が選ばれているか確認する
- [ ] リスト選択後にアイテム本体へフォーカスが移らず、操作できない
  - 発生条件: CommandListBox の選択変更後やスクロール後
  - 影響: Enter / 矢印 / Delete などの操作が効かない
  - 確認方法: 選択変更後に ListBoxItem 自体へフォーカスが移るか確認する
- [ ] テキスト入力欄でキャレットが末尾に戻らない
  - 発生条件: TextBox にフォーカスが入った直後
  - 影響: 文字入力や編集位置が分かりにくくなる
  - 確認方法: フォーカス時にキャレットが末尾へ移動するか確認する

## 確認ポイント

- ボタン名、幅、高さなどの入力が保持されるか
- 参照先ファイルや設定の選択動作が壊れないか
- 作成・保存・キャンセルの導線が崩れないか
- キーボード操作だけで一連の入力が完了できるか

## 補足

- 新しいデグレを見つけたら、この画面の記録に追記する。
