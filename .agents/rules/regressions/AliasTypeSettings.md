# エイリアス型設定画面

## 既知のデグレ

- [ ] 編集開始時に行の高さや余白が変わる
  - 発生条件: F2 などで表示行をインライン編集に切り替えたとき
  - 影響: 行の高さが変わり、上下のレイアウトがずれる
  - 確認方法: 通常表示と編集表示を切り替えて、高さが同じか見る
- [ ] 編集中にフォーカスが抜けると別行へ飛ぶ、または編集が途中終了する
  - 発生条件: 編集中に Tab、矢印キー、別要素へのフォーカス移動が入ったとき
  - 影響: 入力途中の内容が意図せず確定・破棄される
  - 確認方法: テキストボックス間、行ボタン、タブ切り替えの遷移を確認する
- [ ] 行の並び替え後にフォーカスが元の位置へ戻らない
  - 発生条件: Shift+Up / Shift+Down、ドラッグ＆ドロップで行を移動したとき
  - 影響: 連続操作がしづらく、次の編集対象を見失いやすい
  - 確認方法: 並び替え後に対象行へフォーカスが残るか確認する
- [ ] フォーカス移動のループ挙動
  - 発生条件: タブにフォーカスがあるときに上キーを押したとき
  - 影響: 一番下にフォーカスを移動するのがスムーズでなくなる
  - 確認方法: タブにフォーカスがあるときに上キーを押したら、「新規追加」ボタンにフォーカスが当たること

## 確認ポイント

- 画面切り替え時に入力中の状態が壊れないか
- 行追加・削除後にフォーカス移動が崩れないか
- ドラッグ操作とキーボード操作の両方で並び替えできるか
- 編集開始前後で行の高さが変わらないか
