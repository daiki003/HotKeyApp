# Git操作画面

## 既知のデグレ

- [ ] 連続でコマンドを送ると、先に入力したものが待機状態として見えない
  - 発生条件: 実行中に次のコマンドを入力したとき
  - 影響: 入力済みのコマンドが見えず、処理順が分からなくなる
  - 確認方法: 実行中に複数コマンドを入力して、待機中一覧が更新されるか見る
- [ ] `cancel` が待機中の入力に埋もれて、すぐ中断できない
  - 発生条件: 実行待ちのコマンドがある状態でキャンセルしたいとき
  - 影響: 停止したいのに順番待ちが残り、実行が続いてしまう
  - 確認方法: 実行中・待機中の両方で `cancel` を打って中断できるか確認する
- [ ] コンソール出力が更新されても、末尾へ追従しない
  - 発生条件: 実行ログが増えている状態で、コンソールが下端にあるとき
  - 影響: 最新ログが見えなくなる
  - 確認方法: 下端にいる状態で実行し、出力が自動スクロールするか見る
- [ ] Escape の扱いがモード終了とウィンドウ終了で競合する
  - 発生条件: 移動モードや履歴モードから Escape を押したとき
  - 影響: 本来はモードだけ抜けたいのに、画面が閉じてしまう
  - 確認方法: 各モード中に Escape を押して、期待どおりの終了になるか確認する

## 確認ポイント

- 設定画面を開いたときに遷移や戻る操作が崩れないか
- Git設定ダイアログの起動や閉じる動作が壊れないか
- ショートカットやボタン操作の挙動が変わっていないか
